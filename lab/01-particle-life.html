PLATE NOTES — SPECIMEN 01

SOCIAL FIELD · N-BODY RULE TABLE · CATALOG 01/24

Several thousand point masses. Six classes. One table of signed values: row class acts on column class, range −1.00 to +1.00. Negative repels, positive attracts, zero ignores.

Local rule, applied every frame: stay one body-width apart, obey the table inside sensing radius, lose a fixed fraction of velocity per tick. Nothing else. No leader, no objective, no memory.

OBSERVED FORMS

  • Rotating cells with a defined boundary — short-range repulsion plus non-reciprocal pull.
  • Trains: one class follows another at fixed offset. Directional chasing.
  • Lattice sheets — quasi-symmetric table rows, near-equal pull on all sides.
  • Gnawing fronts — a strongly attractive class eroding a repulsive one.

Forms are not stored or replayed. They are the current table's steady behavior. Reweight one cell and the form renegotiates.

OPERATING NOTES

  • Drag on the field: injects a radial force well. Button cycles attract, repel, vortex.
  • Matrix cells: drag vertically. The engine re-balances from the modified table in a few seconds.
  • STATE→URL encodes table and faders into the address line. Reload restores the run.
  • World is a torus. Left edge continuous with right. No boundary layer.

METHOD — SPECIMEN 01

FORCE LAW, INTEGRATOR, NEIGHBOR ENGINE

1 · PAIR FORCE

For a pair at normalized separation x = r / R with table entry F:

x < β f = x/β − 1 core, sign-independent β ≤ x ≤ 1 f = F·(1 − |2x−1−β|/(1−β)) x > 1 f = 0

β = 0.30 nominal. The core term ignores the table: it is volume exclusion. The outer term is a triangular profile, peak at band midpoint.

2 · INTEGRATION

v ← (v + Δt · Σf(r̂) · G) · (1 − λ)^Δt·60 x ← x + v · Δt semi-implicit, then toroidal wrap

Semi-implicit Euler: velocity first, then position with the new velocity. Stable at contact stiffness where explicit Euler fires particles through each other. Friction λ applied as frame-rate-normalized power; identical feel at 30 and 144 Hz.

3 · NEIGHBOR ENGINE

Uniform hash grid, cell edge = R. Each body scans its 3×3 cell block only. Rebuild per frame into flat typed arrays, no allocation, no GC pause. Cost O(n) at bounded density; measured 4,000 bodies inside 2 ms per tick on integrated graphics.

Difference vectors fold by half-world before squaring: d ← d − W·round(d/W). A particle near the left edge sees across the seam at full strength.

4 · STABILITY ENVELOPE

  • G · Δt above ≈ 0.05 ejects pairs from clusters. Observable as boiling.
  • λ below 0.05 leaves undamped drift; structures shear apart.
  • Radius R beyond 90px at fixed population starves the grid; sparse cells, thin structure.

5 · PARAMETERS, DEFAULT PLATE

population 1400 classes 6 R 42px β 0.30 G 1.00 λ 0.12 Δt 0.60 wrap on

Defaults tuned by hand against preset CONVOY. Parameters reproduce it from any seed within ~10s.
