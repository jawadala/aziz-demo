One Frontier, Three Scorings

One loop: keep a frontier, expand its lowest-scored cell. Only the scoring differs:

f(n) = g(n) + h(n) g = exact distance walked from the start h = cheap estimate of distance to the goal

Score by g alone: the frontier floods evenly — Dijkstra, an exact distance field. Score by h alone: the frontier drives at the goal — Greedy. Score by g + h: goal-biased, still shortest-path — A*.

ESTIMATES

Manhattan (4-way): h = |x − gx| + |y − gy| Octile (8-way): h = max(dx,dy) + (√2 − 1)·min(dx,dy) admissible rule: h(n) ≤ true remaining cost → the found path is optimal

An h that never overestimates is admissible: the first goal pop is provably optimal. Greedy's h is not; it carries no guarantee.

THE HEAP

heap: parent(i)=⌊(i−1)/2⌋, children 2i+1, 2i+2 push/pop O(log n); lazy deletion, no decrease-key

THE FLOW FIELD

The flow field computes walking distance to the goal for every cell in one expansion, yielding a scalar field D. Each agent reads D and steers downhill:

D(cell) = uniform-cost distance to the goal steer direction = −∇D (finite differences, 4 neighbours) agent dynamics = v ← v + k·(ŝ·speed − v)

Per-agent cost: O(1) per tick. Pathfinding runs once. 120–300 agents add no search work.

THE TILTED PLATE

The search is untouched. The board reads as a brushed slab set into the dark: walls rise as lit blocks, the route is inlaid as a gold ribbon, and the swarm rides above it as pale beads. The slab carries a camera — drag off the board to swing it, wheel or arrows to pitch; idle, it drifts back to level.

Build Record

Single self-contained sheet. No frameworks, no fonts, no images, no build step.

  • Frontier: binary min-heap, two arrays, lazy deletion, no decrease-key.
  • State sharing: walls + settings RLE-packed into the URL hash. Reduced motion: instant resolve, static frame.
  • Rendering: painter's-sorted projection — one perspective divide per corner, walls extruded and top-lit, no 3-D library.
