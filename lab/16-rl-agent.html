Tabular Q-Learning

No teacher. Q starts at zero. Act, observe reward, update one entry. Repeated updates turn the table into a value map.

1 · STATES, ACTIONS, REWARDS

state s = current cell (24×16 = 384 states) action a = ↓ up ← right (4 actions) reward r = goal (+1.0) · hazard (−1.0) · step (−0.04)

r_step < 0: longer routes cost more; the optimal policy prefers short routes.

2 · THE UPDATE RULE

Q(s,a) ← Q(s,a) + α · [ r + γ · max Q(s′,·) − Q(s,a) ] └────── TD error δ ──────┘

δ = outcome (r plus the discounted max at s′) minus the prediction. α scales the correction, γ the credit back:

  • α — 0.05: slow, stable. 0.99: values oscillate.
  • γ — 0.5: value spreads ~2-3 cells. 0.99: across the map.
  • ε — with probability ε: uniform random action; otherwise argmax Q.
π(s) = argmax Q(s,·) ← greedy policy, drawn as arrows

3 · FAILURE MODES

  • ε = 0 before first goal — greedy from a zero table follows noise; may never reach the goal.
  • α at max — values oscillate. γ near 0.5 — value stops spreading beyond 2-3 cells.
  • Wall painted across a learned route — stale Q-values persist until re-training reroutes.

4 · READING THE PLATE

The value wash is poured in burnished silver: deep oxide for cells that expect loss, bright silver where value concentrates around the goal. Policy arrows are etched in pale chrome. The agent is the bright bead trailing a hairline path; the goal rings in white gold.

Build Record

Single self-contained sheet. No frameworks, no fonts, no build step. Tabular RL stack: agent, environment, reward function, display.

ENGINEERING NOTES

  • Q-table: Float32Array cells×4. The environment returns (s′, r, done); terminals: goal, hazard, cliff, step cap.
  • Per frame: up to 60 environment steps (speed slider), ε-greedy, one-line Q update. Walls editable live.
  • Reduced motion: static frame after 40 pre-trained episodes; STEP still advances.

PERFORMANCE

One step: table lookup, max of 4, one multiply-add; thousands per frame. Canvas repaint (384 cells) dominates; 60 fps integrated.
